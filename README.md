# 2048 - TERMINAL EDITION 🎮

This is a functional, text-based version of the classic **2048** puzzle game, playable directly in your terminal/command line.

> **Built in a single night** as a learning exercise in my first year of college.

### ⚙️ Technologies Used
* **Node.js** (JavaScript runtime)
* The built-in **`readline`** module for handling keyboard input.

### 🚀 How to Run
1.  Ensure you have Node.js installed.
2.  Save the code as a file (e.g., `2048.js`).
3.  Execute it from your terminal:
    ```bash
    node 2048.js
    ```

### 🕹️ Controls
Use the following keys to play:
* **W** or **Up Arrow**: Move Up
* **A** or **Left Arrow**: Move Left
* **S** or **Down Arrow**: Move Down
* **D** or **Right Arrow**: Move Right
* **Ctrl+C**: Quit the game
